
# My Budget Tracker

## Project Description
My Budget Tracker is a simple web application built using HTML and CSS. It helps users organize and track their daily expenses.

## Features

### 1. Expense Table
- Displays five sample expenses.
- Includes Name, Amount, Category, and Date.
- Uses table borders and alternating row colors.
- Includes hover effects.

### 2. Add Expense Form
- Expense name input.
- Amount input in Kenyan Shillings (KSh).
- Category dropdown with five options.
- Date input.
- Add Expense button.

### 3. Multimedia
- Budget Tracker logo using an HTML image element.
- Embedded YouTube budgeting video using an iframe.

### 4. Interactive Elements
- Collapsible instructions using details and summary.
- Hover effects on table rows.
- Focus effects on form inputs.

### 5. Advanced CSS Selectors
- Descendant selector.
- Direct child selector.
- nth-child pseudo-class.
- Negation pseudo-class.
- Focus pseudo-class.
- Hover pseudo-class.
